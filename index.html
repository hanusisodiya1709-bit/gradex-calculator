💡 Viva / Project Examination Questions & Answers

Q1: Why did you use a Dictionary to store marks instead of two separate lists?
Answer: A dictionary establishes a direct key-value mapping between the subject name and its corresponding score. It provides O(1) average-time access, allows easy iteration using marks.items(), and enables calculations via built-in functions like sum(marks.values()).
Q2: How does the application handle invalid marks entered by the user?
Answer: We wrapped user input in a while True loop with a try...except ValueError block. If a user enters non-numeric text or values outside 0 to 100, the error is caught, an informative error message is displayed, and the prompt re-asks without terminating the program.
Q3: How is the Pass/Fail condition determined?
Answer: We implement a two-tier evaluation: first, the overall percentage dictates the grade letter using if / elif / else; second, the check_pass() function verifies that every single subject score is ≥ 40. If any subject is < 40, the final status is set to Fail with backlogs listed.
